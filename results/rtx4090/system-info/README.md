# System of the revision-2 runs

`system.txt`, `lscpu.txt`, `nvidia-smi.csv`, `nvidia-smi-q.txt`, `device-attributes.txt` and the PTX feature probe were written on 2026-10-30 at 08:12, before the first measurement of the revision. The first window is the start of the E0 runner, line 3 of `../e0-run.log`: `2026-10-30T08:46:16+01:00 e0-latency-hiding: Fig. 1 latency hiding (60 points, 1..1181 Muls)`. The last window so far is the check run that counted NaN values, whose end is the last line of `../e4-preprocessing/nan-count/window-run.txt`: `e4-nancount window end 2026-11-01T20:05:07+01:00`.
The log `../e0-run.log` in the repository ends with `# 2026-10-31T20:25:02+01:00 GPU window resize-regression ended`; the start and end of the windows after that are in the `window-run.txt` files (`../pcie-check`, `../e16-attention/ncu`, `../e4-preprocessing/nan-count`) and in the first line (the date) of the `processes-before.txt` and `processes-after.txt` of the folders of the windows.
They describe the one machine on which every result in `results/rtx4090/` and `results/rtx5050/` was made: AMD Ryzen 9 5950X, an RTX 4090 (nvidia-smi index 1, also drives the display) and an RTX 5050 (index 0), **Ubuntu 26.04.1 LTS, kernel Linux 7.0.0-38-generic**, host compiler GCC 15.2.0, NVIDIA driver 610.43.02, CUDA 13.4.3.

**This file covers all windows of the revision.** The kernel was installed on 2026-10-10 (`/boot/vmlinuz-7.0.0-38-generic`, 19:58). The machine booted into it on 2026-10-17 at 19:22:05 (`journalctl --list-boots`; the first kernel log line of that boot is `Linux version 7.0.0-38-generic`) and has not been rebooted since (`uptime -s` of 2026-11-01: 2026-10-17 19:22:04).
So the whole time from the first window (2026-10-30) to now is one boot, one kernel and one OS: no window ran after a reboot into a different kernel, and none ran on another machine or another operating system. The CSV headers of the RTX 4090 results agree: the 330 files with a `# cpu:` line all say `AMD Ryzen 9 5950X 16-Core Processor`, the 375 files with a `# gpu:` line all say `NVIDIA GeForce RTX 4090, cc 8.9, 128 SMs, 24106 MiB`.

The results under `results/rx9060/` and `results/cpu-5800x3d/` are not from this machine: their CSV headers name an `AMD Ryzen 7 5800X3D 8-Core Processor` (and an `AMD Radeon RX 9060` in `rx9060`), not the Ryzen 9 5950X above. The 8 CSV files of `results/rtx5050/` that have a `# cpu:` line name the same Ryzen 9 5950X as this file.

From the commit that adds them on, every CSV header written by `common/system_info.h` and by `pytorch-attention/e16_baselines.py` has the lines `# os:` and `# kernel:` (read at run time from `/etc/os-release` and `uname`), the log of every window, its sampler files and its phases files start with the same two lines (`scripts/os_kernel_lines.sh`, `scripts/load_logger.py`), and the header of `e16_baselines.csv` also has `# nvidia-smi driver:`. Files written before that commit are not edited: for them this file is the record.
